# Spec #005: 评论删除

## 状态: done

## 创建日期: 2026-07-02

---

## 用户故事

As a **评论作者**,
I want **删除我的评论**,
so that **我可以移除不当或过时的内容**.

As an **App 作者**,
I want **删除我作品下的任何评论**,
so that **我可以管理社区内容**.

---

## 问题描述

当前评论发布后无法删除。评论作者写了不合适的评论、或 App 作者想清理评论区的垃圾内容，都无计可施。

---

## 功能范围

### In Scope
- 评论作者删除自己的评论
- App 作者删除其作品下的任何评论
- 删除前二次确认
- 删除后更新 `commentsCount` 计数器

### Out of Scope
- 管理员全局评论管理（需要管理后台）
- 评论编辑（暂不做，保持 MVP 简洁）
- 软删除 / 回收站

---

## 验收标准

- [x] **Given** 我是评论作者, **When** 我点击评论旁删除按钮, **Then** 评论消失且计数器减1
- [x] **Given** 我是 App 作者（非评论作者）, **When** 我查看评论区, **Then** 每个评论旁有删除按钮
- [x] **Given** 我不是评论作者也不是 App 作者, **When** 我查看评论区, **Then** 看不到删除按钮
- [x] **Given** 我点击删除, **When** 确认对话框弹出, **Then** 点击"取消"不删除，点击"确认"执行删除

---

## 非功能需求

- **安全**: 服务端校验权限（不信任客户端隐藏按钮）
- **测试**: 覆盖三种权限场景
