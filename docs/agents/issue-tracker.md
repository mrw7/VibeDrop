# Issue tracker: Local Markdown

Issues and PRDs for this repo live as markdown files under `.scratch/`.

## Conventions

- **Create an issue**: Write a new markdown file in `.scratch/` with format `XXXX-title.md`
- **Read an issue**: Read the markdown file directly
- **List issues**: `ls .scratch/`
- **Update an issue**: Edit the markdown file
- **Close an issue**: Move to `.scratch/archive/` or delete

## File naming

Use sequential numbering: `0001-project-init.md`, `0002-auth.md`, etc.

## When a skill says "publish to the issue tracker"

Create a new markdown file in `.scratch/`.

## When a skill says "fetch the relevant ticket"

Read the markdown file from `.scratch/`.
